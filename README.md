# Dashboard de Fluxo de Caixa | Power BI

## Sobre o projeto

Este projeto foi desenvolvido como parte do meu aprendizado em Business Intelligence, durante um curso de Power BI.

A proposta foi construir um dashboard para análise de fluxo de caixa, explorando recursos de visualização de dados e organização de informações financeiras.

## Análises apresentadas

- Receitas, despesas e saldo financeiro;
- Movimentações financeiras por período;
- Distribuição de despesas por setor;
- Despesas por classificação;
- Detalhamento das movimentações financeiras.

## Recursos utilizados

- Indicadores financeiros (KPIs);
- Gráfico de linhas;
- Gráfico de rosca;
- Gráfico de barras;
- Filtros interativos por ano e setor.

## Ferramenta

Microsoft Power BI.

## Aprendizados

Durante o desenvolvimento, pratiquei a construção de dashboards, organização de informações, utilização de elementos visuais e análise de dados financeiros.
